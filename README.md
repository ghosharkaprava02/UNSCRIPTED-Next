# UNSCRIPTED Next

**Intelligence is not authority.** A separate futuristic edition of Arkaprava Ghosh's Flipkart APM prototype.

## Try it

[Open the interactive prototype](https://ghosharkaprava02.github.io/UNSCRIPTED-Next/)

No installation or sign-in is required. Every action is a fictional simulation. No payment, message, job response, external AI call or private-data access occurs.

You can also download `index.html` and double-click it. All code, artwork and styles are embedded, so it works offline.

## Walkthrough

1. **Decision room:** give your own first reaction to a Tokyo offer before seeing the agent's recommendation. Explore, explicitly authorize rejection, or defer. Exploring never accepts the job.
2. **Financial boundary:** a ₹2,00,000 investment exceeds a ₹25,000 contract. Raising the limit changes the policy result, but does not approve a transaction.
3. **Privacy shield:** the agent cannot disclose a friend's private information on your authority. Evaluate a generic alternative separately.
4. **Intent contracts:** adjust scope, caps, recipients, freshness and expiry; inspect the rule evaluation.
5. **Decision passports:** inspect and export the contract, proposal, intent, rules and simulated outcome.

The purple action gateway illustrates permission routing. A drifting starfield, floating typography, orbital labels, and a slow perspective crawl give the interface a space-cinematic feel. These are decorative animations, not live AI activity. Use **Pause motion** in the top bar to pause them. Motion pauses outside the viewport, and reduced-motion preferences are respected.

## Independence

This repository and GitHub Pages deployment are separate from the original submission. The original site, PDFs and backups are unchanged. This edition uses its own `unscripted.next.v1` browser-storage namespace. Reset clears only this edition's demo state. The permission engine is an unchanged copy of the original.

Original: https://ghosharkaprava02.github.io/DA25C003_Flipkart-APM-/

## Source

`index.html` is the self-contained published build. `engine.js`, `app.js`, `styles.css`, `motion.js`, `next.css`, `palette.css`, `cinematic.js`, `cinematic.css`, and `brand.svg` are the readable implementation files. Motion scripts change presentation only and never grant permission or submit decisions. Seeded records are labeled simulated; the audit is editable local demo data, not signed evidence.
